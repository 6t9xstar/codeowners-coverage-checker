# Security policy

## Supported versions

The latest released version of OwnerScope receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting:
https://github.com/6t9xstar/codeowners-coverage-checker/security/advisories/new

You will get a response within 7 days. OwnerScope reads local files and never sends repository contents anywhere (only the optional `--github` mode calls the GitHub API, with owner names and the repository name).
